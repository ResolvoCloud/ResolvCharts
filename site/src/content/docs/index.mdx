## Quick start

```ts
import { createChart } from "resolvcharts";

const chart = createChart(document.querySelector("#chart"), {
  type: "line",
  curve: "smooth",
  flow: true, // continuous, water-like motion on live data
  window: 30, // sliding view
  maxPoints: 200, // hard memory cap
  data: { x: xs, series: [{ label: "CPU %", y: ys }] },
});

chart.append(Date.now(), value); // streams smoothly, zero-alloc steady state
```

## Why

- **Zero dependencies** — ~21 kB gzipped ESM.
- **Fast** — typed arrays, M4 raster-perfect decimation, zero-alloc live append.
- **16 chart types** — line, area, bar, combo, sparkline, scatter, bubble, rangearea, donut, pie, radar, funnel, candle, ohlc, waterfall, baseline.
- **Optional WebGPU** — `renderer: "auto"` rasterizes series on the GPU; axes, grid and tooltips stay on Canvas2D.
