why it's fast

Pixels, not points

Whole-frame memoAn unchanged view returns before clearRect — a repeat render is a key compare, ~0.01 ms.
M4 decimationAt most ~4 points per pixel column, peaks preserved — cold-render cost is bounded by plot width.
WebGPU when it countsrenderer: "auto" engages the GPU past 50k points — instanced draws, ring-buffer uploads.
Zero-alloc streamingappend() shifts typed arrays in place — ~0.05 ms per call, 120 fps sustained.
